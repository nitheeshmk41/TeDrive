# Using TeDrive

## Where your files live

Everything you add is a message in a private channel called **TeDrive Storage** in your Telegram account. Only you can see it. Telegram allows files up to 2 GB each (4 GB with Premium).

## Photos

- **Timeline** grouped by day, with **On this day** memories at the top.
- Tap a photo to open it. On mobile data only the preview loads; tap **Load full photo** for the original (data saver). On Wi-Fi the full photo loads by itself.
- In the viewer, pinch to zoom and swipe for the next one. On a computer use the arrow keys or the side buttons.
- **ⓘ Details** shows the date, size, camera and, if the photo has GPS data, a map of where it was taken.
- **Map** view shows every photo that has a location. Locations are read from photos when they are uploaded.

## Files and folders

- **Add** uploads files. On a computer you can also drag files onto the window.
- Folders can be nested; the path at the top takes you back up.
- Long-press to select many files, then star, move, share, download or delete them together.
- **Starred**, **Recent**, **Large files** and **Duplicates** views help clean up.
- **Trash** keeps deleted files for 30 days; restore them from there.
- **Offline** lists files already downloaded to this device.

## Phone backup (Android)

**Backup** uploads photos and videos from the albums you choose, in the background. You can limit it to Wi-Fi or charging. **Free up space** removes phone copies only after Telegram holds an identical copy (checked by SHA-256 fingerprint).

## Sharing

Open a file's **Share** menu:

- **Send the file** shares the file itself to WhatsApp, email or any app.
- **Send a smaller copy** (photos, Android) sends a reduced copy of about 300 KB.
- **Send to a Telegram chat** forwards the file to a chat you pick. Telegram copies it on its own servers, so nothing is downloaded and no data is used. Select several files to forward them together.
- **Open in Telegram** shows the file in the Telegram app, where you can view or download it. Folders have the same button.
- **Wi-Fi transfer** moves files to a laptop or phone on the same Wi-Fi.
- In a folder, the **zip** button packs the whole folder into one .zip file to send or save.

TeDrive no longer makes public links. A file that still has one from an older version shows **Remove old public link**.

## Vault

The **Vault** is for documents such as Aadhaar, PAN or passport scans. Files are encrypted on your device with your passphrase before upload, so even Telegram cannot read them. If you forget the passphrase, the files cannot be recovered.

## App lock

**Account → App Lock** sets a 4-digit PIN. On phones with a fingerprint sensor you can also turn on **Unlock with fingerprint**. The app locks after 30 seconds in the background.

## Wi-Fi transfer

In the Android or desktop app, **Wi-Fi transfer** shows an address and a QR code. On another phone or computer on the same Wi-Fi, open the address in a browser to download files from this device or send files to it; files sent to it are added to your drive. No internet data is used. The web app cannot do this, because browsers cannot accept connections.

## Uploads and downloads

Up to 3 files upload at the same time. Selecting several files and choosing Download or Share fetches 4 at a time.

## Updates

**Account → Check for updates** shows whether a newer version exists. See [Install → Updating](install.md#updating).
